Ecuaciones de segundo grado

Ordena los pasos

Resolver x² + 2 = 3x

Ordena los pasos para resolver \(x^2 + 2 = 3x\).

  • Pasar todo al primer miembro: \(x^2 - 3x + 2 = 0\).
  • Leer los coeficientes: \(a = 1\), \(b = -3\), \(c = 2\).
  • Calcular el discriminante: \(\Delta = (-3)^2 - 4\cdot 1\cdot 2 = 1\).
  • Aplicar la fórmula: \(x = \frac{3 \pm 1}{2}\).
  • Escribir las soluciones: \(x_1 = 2\), \(x_2 = 1\).
  • Comprobar: \(2^2 + 2 = 3\cdot 2\) y \(1^2 + 2 = 3\cdot 1\).
