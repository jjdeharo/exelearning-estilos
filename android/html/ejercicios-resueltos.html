Ecuaciones de segundo grado

Ejercicios resueltos

Cómo trabajar

Resuelve cada ecuación en tu cuaderno antes de pulsar «Ver solución». Fíjate primero en si es completa o incompleta.

Ejercicio 1

Resuelve \(x^2 - 49 = 0\).

Es incompleta, sin término en \(x\):

\[ x^2 = 49 \;\Rightarrow\; x = \pm\sqrt{49} = \pm 7 \]

Soluciones: \(x_1 = 7\) y \(x_2 = -7\).

Ejercicio 2

Resuelve \(5x^2 + 20x = 0\).

Es incompleta, sin término independiente:

\[ 5x\,(x + 4) = 0 \;\Rightarrow\; x_1 = 0, \quad x_2 = -4 \]

Ejercicio 3

Resuelve \(x^2 - 2x - 15 = 0\).

Es completa, con \(a = 1\), \(b = -2\) y \(c = -15\). El discriminante es \(\Delta = 4 + 60 = 64\):

\[ x = \frac{2 \pm \sqrt{64}}{2} = \frac{2 \pm 8}{2} \;\Rightarrow\; x_1 = 5, \quad x_2 = -3 \]

Ejercicio 4

Resuelve \(4x^2 + 4x + 1 = 0\).

El discriminante es \(\Delta = 16 - 16 = 0\): hay una solución doble.

\[ x = \frac{-4}{2\cdot 4} = -\frac{1}{2} \]

La ecuación es \((2x + 1)^2 = 0\), y solo se cumple con \(x = -\frac{1}{2}\).

Ejercicio 5

Resuelve \(3x^2 - x + 2 = 0\).

El discriminante es \(\Delta = (-1)^2 - 4\cdot 3\cdot 2 = 1 - 24 = -23\). Es negativo: la ecuación no tiene solución real.

Ejercicio 6

Resuelve \(x\,(x + 3) = 10\).

Primero se quita el paréntesis y se pasa todo a un miembro: \(x^2 + 3x - 10 = 0\). El discriminante es \(\Delta = 9 + 40 = 49\):

\[ x = \frac{-3 \pm 7}{2} \;\Rightarrow\; x_1 = 2, \quad x_2 = -5 \]

Comprobación: \(2\cdot 5 = 10\) y \((-5)\cdot(-2) = 10\).

Ejercicio 7

Resuelve \((x - 1)^2 = 2x + 7\).

Se desarrolla el cuadrado y se pasa todo a un miembro:

\[ x^2 - 2x + 1 = 2x + 7 \;\Rightarrow\; x^2 - 4x - 6 = 0 \]

El discriminante es \(\Delta = 16 + 24 = 40\), que no es un cuadrado perfecto, así que las soluciones llevan una raíz:

\[ x = \frac{4 \pm \sqrt{40}}{2} = \frac{4 \pm 2\sqrt{10}}{2} = 2 \pm \sqrt{10} \]

Soluciones: \(x_1 = 2 + \sqrt{10} \approx 5{,}16\) y \(x_2 = 2 - \sqrt{10} \approx -1{,}16\).
