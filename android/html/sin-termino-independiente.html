Ecuaciones de segundo grado

Sin término independiente

Método

En \(ax^2 + bx = 0\) se saca factor común \(x\). Un producto vale cero solo si alguno de sus factores es cero, así que la ecuación se separa en dos de primer grado:

\[ ax^2 + bx = 0 \;\Rightarrow\; x\,(ax + b) = 0 \;\Rightarrow\; \begin{cases} x = 0 \\ ax + b = 0 \;\Rightarrow\; x = -\dfrac{b}{a} \end{cases} \]

Ejemplo resuelto

Resolvemos \(3x^2 - 12x = 0\).

\[ 3x^2 - 12x = 0 \;\Rightarrow\; 3x\,(x - 4) = 0 \;\Rightarrow\; x_1 = 0, \quad x_2 = 4 \]

Comprobación con \(x = 4\): \(3\cdot 4^2 - 12\cdot 4 = 48 - 48 = 0\).

Siempre tiene dos soluciones

Este tipo de ecuación tiene siempre dos soluciones reales distintas, y una de ellas es \(x = 0\).

Error frecuente

Dividir los dos miembros entre \(x\): de \(3x^2 = 12x\) se pasaría a \(3x = 12\) y se perdería la solución \(x = 0\). No se puede dividir entre \(x\) sin saber si vale cero; por eso se saca factor común.
