Ecuaciones de segundo grado

La fórmula general

La fórmula

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

El signo \(\pm\) indica que hay que hacer dos cálculos, uno sumando la raíz y otro restándola. Cada uno da una solución.

Paso a paso

  1. Pasar todos los términos a un miembro y ordenarlos: \(ax^2 + bx + c = 0\).
  2. Escribir los coeficientes con su signo.
  3. Calcular el discriminante, \(b^2 - 4ac\).
  4. Sustituir en la fórmula y calcular las dos soluciones.
  5. Comprobar el resultado en la ecuación de partida.

Ejemplo resuelto

Resolvemos \(2x^2 - 7x + 3 = 0\), con \(a = 2\), \(b = -7\) y \(c = 3\).

\[ x = \frac{-(-7) \pm \sqrt{(-7)^2 - 4\cdot 2\cdot 3}}{2\cdot 2} = \frac{7 \pm \sqrt{49 - 24}}{4} = \frac{7 \pm 5}{4} \]

\[ x_1 = \frac{7 + 5}{4} = 3, \qquad x_2 = \frac{7 - 5}{4} = \frac{1}{2} \]

Comprobación:

\[ 2\cdot 3^2 - 7\cdot 3 + 3 = 18 - 21 + 3 = 0 \]

\[ 2\cdot\left(\frac{1}{2}\right)^2 - 7\cdot\frac{1}{2} + 3 = \frac{1}{2} - \frac{7}{2} + 3 = 0 \]

De dónde sale

La fórmula se obtiene completando un cuadrado en \(ax^2 + bx + c = 0\).

Se multiplican los dos miembros por \(4a\) y se suma \(b^2\) a los dos:

\[ 4a^2x^2 + 4abx + 4ac = 0 \;\Rightarrow\; 4a^2x^2 + 4abx + b^2 = b^2 - 4ac \]

El primer miembro es el cuadrado de \(2ax + b\). Sacando la raíz cuadrada y despejando \(x\):

\[ (2ax + b)^2 = b^2 - 4ac \;\Rightarrow\; 2ax + b = \pm\sqrt{b^2 - 4ac} \;\Rightarrow\; x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Error frecuente

Olvidar el signo de \(b\). Si \(b = -7\), el numerador empieza por \(-(-7) = 7\). Y \(b^2\) nunca es negativo: \((-7)^2 = 49\), no \(-49\).
